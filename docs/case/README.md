# The Zvukopis case

3D-printed cases for the Waveshare ESP32-S3-ePaper-3.97 board, one STL and
one exploded view per version. The case bolts to the board's standoffs with
four countersunk M2.5×6 bolts, hex or Torx. The build steps are on the
[project page](https://zvukopis.lom.audio/#build).

| Version | Date | Files | Notes |
|---|---|---|---|
| v2 | 2026-11-13 | [zvukopis-case-v2.stl](zvukopis-case-v2.stl), [zvukopis-case-v2.step](zvukopis-case-v2.step) | Wider bolt holes (3 mm) with shallower countersinks, stronger walls, the speaker holes moved 0.6 mm. The same outline, and it goes together like v1. Comes with a STEP file for changing it. |
| v1 | 2026-11-02 | [zvukopis-case-v1.stl](zvukopis-case-v1.stl), [zvukopis-case-v1.png](zvukopis-case-v1.png) | The first case. Prints on an FDM or a resin printer. |

A new version gets the next number in both file names, a row here, and a row
in the case list on the project page (`docs/index.html`, the Build section,
by the title), where the 3D view and the parts list also name the file.
